# Resilience

Placeholder for designing a system to withstand faults, limit their impact, degrade gracefully, and recover within defined objectives.

Resilience spans prevention, isolation, continued operation, and recovery. Typical techniques include timeouts, bounded retries, circuit breakers, bulkheads, fallbacks, and recovery exercises; each has costs and failure modes.
