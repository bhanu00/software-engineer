# Availability

Placeholder for defining availability, service-level objectives, error budgets, downtime measurement, redundancy, and failover expectations.

Availability describes whether a system is usable when a request is made. It is related to, but distinct from, reliability: a system can experience failures and still maintain high availability if recovery is fast.
