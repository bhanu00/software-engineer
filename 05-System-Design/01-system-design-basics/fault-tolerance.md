# Fault Tolerance

Placeholder for continuing critical service when components fail through redundancy, replication, isolation, failover, and recovery design.

Fault tolerance is one part of resilience: it aims to keep a required capability operating despite specified faults, while resilience also includes containment, graceful degradation, and recovery.
