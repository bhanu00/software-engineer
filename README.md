# Software Engineering Handbook

A practical learning library covering programming, cloud operations, system design, applied case studies, and engineering interviews. It includes study notes, diagrams, and implementation samples.

## Start

- Follow the [learning path](LEARNING_PATH.md) for a suggested sequence or choose a goal-specific route.
- Use the [topic index](INDEX.md) to find a subject directly.
- Begin with [Programming and OOP](1-Programming-and-OOP/README.md) if you are new to the material.
