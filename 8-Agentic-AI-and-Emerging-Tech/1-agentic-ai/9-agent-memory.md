# Agent Memory

## Scope

Short-term, task, and long-term memory with appropriate retention and privacy policies.

## Topics

- Conversation history and context-window management.
- Task state and durable workflow memory.
- Long-term preferences, consent, correction, and deletion.
- Memory relevance, staleness, conflicts, and summarization.
- Tenant isolation, retention, encryption, and access control.

## Architect questions

- Why is this information memory instead of ordinary application data?
- Who can read, update, or delete it?
- How is stale or incorrect memory corrected?
