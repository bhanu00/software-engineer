# Model Context Protocol

## Scope

MCP host, client, and server concepts, tool discovery, authentication, consent, and isolation.

## Topics

- Host, client, server, resources, prompts, and tools.
- Capability discovery and typed tool contracts.
- Authentication, authorization, consent, and scoped credentials.
- Tool isolation, input validation, output handling, and audit logs.
- Versioning, quotas, lifecycle, and server trust.

## Architect questions

- Which principal is authorized to invoke a tool?
- How are tool descriptions and inputs treated as untrusted data?
- How are tools discovered, approved, monitored, and revoked?
