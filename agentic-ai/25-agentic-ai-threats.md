# Agentic AI Threats

## Scope

Prompt injection, data poisoning, model extraction, tool abuse, supply chain, and denial of wallet.

## Topics

- Direct and indirect prompt injection.
- Sensitive-data leakage and unauthorized retrieval.
- Data poisoning, model manipulation, and model extraction.
- Tool abuse, excessive agency, unsafe output handling, and privilege escalation.
- Dependency, model, provider, and MCP supply-chain risk.
- Denial of service and denial of wallet.

## Architect questions

- What is untrusted input and where is it isolated?
- What is the blast radius of a compromised tool or model?
- Which controls prevent, detect, and contain each threat?
