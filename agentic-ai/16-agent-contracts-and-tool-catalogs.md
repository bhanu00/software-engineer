# Agent Contracts and Tool Catalogs

## Scope

Define reusable contracts for agents, tools, permissions, and operational behavior.

## Topics

- Purpose, inputs, outputs, state, tools, permissions, and ownership.
- Preconditions, postconditions, errors, timeouts, and SLOs.
- Tool catalog metadata, schemas, examples, risk levels, and owners.
- Versioning, compatibility, deprecation, and contract testing.
- Discovery, approval, quotas, and audit requirements.

## Architect questions

- Can another team onboard this agent without platform changes?
- Are permissions and side effects explicit in the contract?
- How are incompatible changes detected before deployment?
