# Agent Tracing and Observability

## Scope

Trace model calls, retrieval, tools, state transitions, prompts, versions, and outcomes.

## Topics

- End-to-end correlation IDs and workflow run IDs.
- Spans for model inference, retrieval, tool calls, approvals, and state transitions.
- Prompt, model, tool, dataset, and policy versions.
- Redacted logs, metrics, traces, and retention controls.
- Debugging, replay, cost attribution, and user feedback.

## Architect questions

- Can an operator explain a bad outcome from one trace?
- Are sensitive prompts, documents, and outputs protected?
- Which signals detect quality regressions before users report them?
