# Prompt and Model Versioning

## Scope

Canary releases, rollback, feature flags, and CI/CD gates for AI behavior.

## Topics

- Version prompts, models, tools, datasets, policies, and workflow definitions.
- Reproducibility and traceability for every run.
- Offline evaluation, shadow traffic, canaries, and gradual rollout.
- Feature flags, rollback, migration, and compatibility.
- Release gates for quality, safety, latency, and cost.

## Architect questions

- Can a bad prompt or model release be rolled back independently?
- What evidence is required before production exposure?
- How are changes communicated to downstream teams and auditors?
