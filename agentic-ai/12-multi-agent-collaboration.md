# Multi-Agent Collaboration

## Scope

Roles, delegation, shared state, arbitration, and when multi-agent designs add complexity.

## Topics

- Specialist roles such as researcher, analyst, planner, executor, and reviewer.
- Agent contracts, handoffs, shared state, and evidence passing.
- Delegation boundaries, permissions, budgets, and maximum turns.
- Arbitration, disagreement, review, and deterministic final validation.
- Comparing multi-agent designs with one agent or a conventional workflow.

## Architect questions

- Does each agent have a distinct responsibility?
- Does collaboration improve quality enough to justify cost and failure modes?
- Which agent or human owns the final outcome?
