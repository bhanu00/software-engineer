# Evaluation-Driven Development

## Scope

Golden datasets, deterministic checks, rubric grading, replay, and red teaming.

## Topics

- Task datasets covering normal, edge, failure, and adversarial cases.
- Schema, citation, policy, and deterministic assertions.
- Rubric-based or model-assisted grading with stable criteria.
- Regression comparison across prompts, models, tools, and workflows.
- Replay, release thresholds, red teaming, and human review.

## Architect questions

- What does success mean for this workflow?
- Which failures block release and which require monitoring?
- Can a production incident become a permanent regression test?
