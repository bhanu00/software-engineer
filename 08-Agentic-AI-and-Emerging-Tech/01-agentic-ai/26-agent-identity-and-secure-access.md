# Agent Identity and Secure Access

## Scope

Identity propagation, least privilege, tenant isolation, scoped credentials, just-in-time access, and secure gateways.

## Topics

- User identity propagation and workload identity.
- Least-privilege tool permissions and scoped credentials.
- Tenant isolation, service authorization, and policy enforcement.
- Just-in-time access, approval, revocation, and expiration.
- Secure model/tool gateways, quotas, and audit logs.

## Architect questions

- Whose authority is the agent exercising?
- Can an agent gain permissions through prompt content?
- How quickly can access be revoked during an incident?
